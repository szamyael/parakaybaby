# Visual Stories Lab

A self-contained Grade 10 English educational website built from the uploaded lesson PDF **“Technical Editing and Animation”**.

## Includes

- Persistent lesson navigation with scroll progress
- Structured coverage of all 20 lesson sections
- Interactive water-cycle technical-editing demonstration
- Technical Editing vs. Video Editing sorting activity
- Documentary before/after visual example
- Animated demonstrations of animation concepts
- Process tabs for Water Cycle, Human Body, Earthquake, and Solar System
- Four animation-type demonstrations
- Purposeful-animation comparison
- Earthquake Safety sequence interaction
- Vector scaling explorer
- Vector → Technical Editing → Animation connection diagram
- SHOW IT → MOVE IT → CHECK IT memory formula
- Interactive recycling-video scene timeline
- Critical-viewer question checklist
- Four-concept comparison table
- Complete volcano example walkthrough
- Surprise-question modal with instant feedback
- 8-question quiz with scoring and explanations
- Hands-on 4-scene storyboard activity with local browser saving and print/export
- Responsive mobile/tablet/desktop layout
- No external libraries required

## Run locally

Open `index.html` in a modern browser. No server or package installation is required.

For a local development server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in the folder.

## Source basis

The instructional content is based on the uploaded PDF lesson. The site preserves the lesson's terminology and core distinctions:

- Technical Editing = check/improve accuracy, clarity, consistency, organization, and appropriateness.
- Animation = create the appearance of movement to help explain information.
- Vector = create clear, scalable visual elements.
- Video Editing = arrange and modify video/audio elements.
- Memory guide: **VECTOR — SHOW IT / ANIMATION — MOVE IT / TECHNICAL EDITING — CHECK IT / VIDEO EDITING — ARRANGE IT**.
